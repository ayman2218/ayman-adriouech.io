# Embedded ADAS prototype — Raspberry Pi

**Focus:** Embedded computer vision, traffic-sign recognition, lane-departure detection and real-time motor control.

As described in the engineering CV, this prototype combines camera perception, CNN-based image analysis and motor actuation on a Raspberry Pi.

## Engineering topics
- Camera acquisition and preprocessing with OpenCV
- Road sign and lane-related visual signals
- Compact CNN inference
- Connecting perception output to embedded motor commands

**Source status:** This is a project summary from the CV. No independently identified public code has been added here. Reported behavior should not be interpreted as validated automotive-grade ADAS.
