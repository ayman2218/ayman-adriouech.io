# Vision-based chess-playing robotic arm

**Focus:** Board perception, inverse kinematics, Raspberry Pi and robotic manipulation.

This student project combines visual recognition of a chessboard with inverse-kinematics-based positioning of a robotic arm to execute game moves.

## Intended technical pipeline
Camera → board-state recognition → move interpretation → inverse kinematics → robotic arm commands.

A related GitHub repository exists at [ros2_chess_ws](https://github.com/ayman2218/ros2_chess_ws), but it was empty when inspected; it is **not** presented as published source code.
