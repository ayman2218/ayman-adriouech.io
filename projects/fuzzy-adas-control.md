# Fuzzy-logic controller for ADAS-like functions

**Focus:** Fuzzy rules, Raspberry Pi 5, line following, automatic parking and hardware-in-the-loop experimentation.

The CV documents a fuzzy-logic embedded control prototype for assisted parking and line following. In the technical portfolio, fuzzy logic is presented as a way to represent environmental uncertainty rather than relying on a binary classifier.

## Engineering topics
- Definition of fuzzy membership functions and IF–THEN rules
- Sensor-input fuzzification and control decision logic
- Actuator command generation
- Hardware-in-the-loop validation

**Source status:** The source implementation and HIL logs have not been provided. This document does not claim production ADAS qualification.
