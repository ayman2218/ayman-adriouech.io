# Autonomous vehicle control — CARLA

**Technology:** Python, CARLA simulator, PID, Stanley controller, kinematic and dynamic vehicle models.

A control and simulation project targeting **longitudinal speed regulation using PID** and **lateral path tracking using Stanley control**. The project focuses on vehicle-state feedback, waypoint following and validation in a simulated environment.

**Planned reproducibility material:** controller source, CARLA release/dependencies, scenarios, plots for speed/tracking error, and a setup walkthrough.

**Source availability:** The user's CV documents this project. Controller files and simulation assets have not yet been supplied for publication; this is a project description rather than executable source.
