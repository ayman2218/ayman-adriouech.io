# Autonomous wheelchair — ROS 2 navigation

**Technology:** ROS 2, Nav2, LiDAR, IMU, SLAM, RViz, URDF / TF.

An autonomous wheelchair simulation and navigation project featuring LiDAR-based 2D mapping, Nav2 path planning, wheel-odometry/IMU fusion and coordinate transforms for chassis and wheels.

**Demonstrated in the portfolio:** simulation and obstacle avoidance visualized in RViz.

**Source availability:** The project is documented in the author's technical portfolio; the exact public source repository has not yet been identified. Related public ROS 2 work can be found at [GitHub repositories](https://github.com/ayman2218?tab=repositories).
