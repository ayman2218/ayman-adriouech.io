P-01 · Edge AI / Automobile2024

Compression de modèles Deep Learning pour ECU

Pipeline intégré de Pruning, Quantization et Knowledge Distillation (PQK) pour déployer un détecteur YOLOv5 sur calculateur automobile, évalué sur le dataset GTSRB.

Le problème — à 30 Hz, un ADAS dispose de 33 ms par trame. Le YOLOv5-nano de référence en demande ~45 ms sur une ECU standard (RAM < 512 MB, pas de GPU) : deadline violée.

K

P-02 · Vision / Robotique d'assistance2025

Robot mobile autonome de détection de chutes

Robot compagnon qui identifie la chute d'une personne vulnérable par vision, sans capteur porté, et alerte les soignants. Plutôt qu'un LSTM trop lourd pour un Raspberry Pi 5, un algorithme déterministe fondé sur la géométrie du squelette MediaPipe (33 points 3D).

# Fall Score — 3 indicateurs, alarme si > seuil pendant 4 s
R_corps = |y_nez − y_hanche| / H → < 0.45
θ_tronc = |atan2(Δy, Δx)|·180/π → < 60°
V_y = y_hanche(t) − y_hanche(t−4) → > 0.03

Priorité sécurité (HARA) : à la détection, une interruption gèle immédiatement les moteurs pour éviter toute collision. Usage CPU de l'algorithme < 5 %, inférence à 30 FPS sans GPU.
